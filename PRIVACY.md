# Privacy Policy

Foundation Explorer is a business-to-business research platform. Its foundation
and grant records come from public IRS filings and concern organizations,
institutional recipients, and contact information reported on public tax forms.
We do not build consumer profiles from private data.

## Information Processed by the Application

- Search terms, filters, and page requests are processed to return results.
- In the current demo, saved foundation EINs are stored in the user's browser
  using `localStorage`; filter state is stored using `sessionStorage`. This
  browser state is not an account and can be cleared through browser controls.
- The hosting provider may process ordinary delivery logs such as IP address,
  request time, user agent, and requested URL for security and operations.
- The current application does not include advertising trackers or behavioral
  analytics code.

## AI Processing

Classification of public source records (organization names, EINs, and mission
statements drawn from public IRS filings) may be processed using deterministic
code and language models, which may include a commercial LLM API, during
documented build-time classification runs. Customer data — your searches, saved
lists, and account activity — is never submitted to any third-party LLM API for
classification or training.

This statement does not mean no service provider processes any network data:
the web host necessarily handles requests needed to deliver the application.

## Third-Party Links

The product may show an outbound link to a public ProPublica organization page.
Foundation Explorer does not use ProPublica as an API or backend data source.
When a user follows the link, the browser contacts ProPublica directly, and its
privacy policy and terms apply.

## Data Retention and Security

Public-source releases and their provenance are retained to support audit and
reproducibility. Operational logs are retained only as needed for security,
diagnostics, and legal obligations. No security control can guarantee absolute
protection; access to nonpublic operational systems is limited to authorized
personnel.

Questions or deletion requests concerning nonpublic account data should be sent
through the official Foundation Explorer support channel. Public IRS source
records must be corrected through the IRS or the filing organization.
